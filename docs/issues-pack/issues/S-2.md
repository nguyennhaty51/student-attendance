**Người làm:** cả nhóm (mỗi người một phần)
**Tham chiếu tài liệu:** README.md
**Phụ thuộc:** S-1
**Nhánh:** `feature/tv<n>-hello`
**Kích thước:** S (S nửa ngày, M một ngày, L hai ngày trở lên)   **Milestone:** M0 - Thiết lập

### Việc cần làm
- [ ] Clone repo, `git checkout develop`.
- [ ] Tạo môi trường ảo, `pip install -r requirements.txt`, chạy `pytest` (phải xanh).
- [ ] Chạy `flask --app app:create_app run --debug` và mở được trang chủ.
- [ ] Tạo nhánh `feature/tv<n>-hello`, thêm tên mình vào mục Thành viên trong `README.md`, mở Pull Request vào `develop`.
- [ ] Người duyệt theo vòng chéo trong `CONTRIBUTING.md` duyệt và ghép.

### Tiêu chí hoàn thành
- [ ] Cả 5 người đã có 1 Pull Request được ghép vào `develop`.
- [ ] Mọi người chạy được ứng dụng và `pytest` trên máy mình.

### Quy tắc
- Làm trên nhánh riêng tách từ `develop`; mở Pull Request vào `develop` kèm `Closes #<số Issue này>`.
- Người duyệt theo vòng chéo trong `CONTRIBUTING.md`; CI (`pytest`) phải xanh mới được ghép.
