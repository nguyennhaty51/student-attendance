**Người làm:** cả nhóm (mỗi người tự làm phần của mình)
**Hạn:** Ngày 1   **Mốc:** Ngày 1-2: Nền tảng
**Tham chiếu tài liệu:** README.md, CONTRIBUTING.md, Mục 4.5, Mục 5
**Phụ thuộc:** —
**Nhánh gợi ý:** `feature/tv<n>-hello` (mỗi nhóm việc nhỏ một Pull Request)

### Việc của mỗi người
- [ ] Clone repo, `git checkout develop`, tạo môi trường ảo, `pip install -r requirements.txt`, chạy được ứng dụng (`flask --app app:create_app run --debug`).
- [ ] Tạo nhánh `feature/tv<n>-hello`, thêm tên mình vào mục Thành viên trong `README.md`, mở Pull Request vào `develop`; người duyệt theo vòng chéo trong `CONTRIBUTING.md`.
- [ ] Đọc đặc tả chi tiết các use case của phần mình (Mục 4.5), sơ đồ lớp (Mục 5) và ERD (Mục 6).
- [ ] Họp 30–45 phút cuối ngày 1: TV1 trình bản nháp `docs/api_contract.md`, cả nhóm chốt các chỗ còn lệch.

### Tiêu chí hoàn thành
- [ ] Cả 5 người có 1 Pull Request được ghép vào `develop`.
- [ ] Mọi người chạy được ứng dụng trên máy mình.
- [ ] Cả nhóm đã đồng ý bản nháp hợp đồng frontend–backend.

### Quy tắc
- Làm trên nhánh tách từ `develop`, mở Pull Request vào `develop`, nhắc Issue này (`Closes #<số Issue>` khi Pull Request cuối cùng của Issue được ghép).
- Chỉ sửa file thuộc phần của mình; cần đổi file dùng chung thì báo TV1.
- Kiểm thử sẽ làm sau khi hoàn thành chức năng, theo Testing Document Template của thầy.
