**Người làm:** TV1
**Hạn:** Ngày 5-7   **Mốc:** Ngày 6-7: Ghép nối và hoàn thiện
**Tham chiếu tài liệu:** Guidelines for group projects (Docker, GitHub); Mục 2 (NFR)
**Phụ thuộc:** Các Issue chức năng
**Nhánh gợi ý:** `feature/t1-docker, docs/demo` (mỗi nhóm việc nhỏ một Pull Request)

### Docker
- [ ] Cập nhật `Dockerfile` và `docker-compose.yml`: dịch vụ ứng dụng và MySQL, biến môi trường trong `.env`, tự chạy migration (và seed khi cần).
- [ ] Ghi hướng dẫn `docker compose up --build` trong README.

### Ghép nhánh và rà soát
- [ ] Duyệt Pull Request, xử lý xung đột, giữ `develop` luôn chạy được; ghép `develop` vào `main` ở cuối.
- [ ] Rà soát nhanh các yêu cầu phi chức năng chính: mật khẩu bcrypt, phân quyền, mã PIN hết hạn, lịch sử sửa, giao diện co giãn.

### Hoàn thiện nộp bài
- [ ] Hoàn thiện README (cài đặt, tài khoản mẫu, cấu trúc thư mục, bảng ánh xạ lớp).
- [ ] Viết kịch bản demo theo thứ tự: sinh viên điểm danh bằng mã, giảng viên mở phiên và sửa điểm danh, quản trị xem báo cáo; gắn thẻ `v1.0` trên `main`.

### Tiêu chí hoàn thành
- [ ] `docker compose up --build` chạy được trên máy sạch.
- [ ] `main` chạy được và có thẻ `v1.0`.
- [ ] Demo chạy trọn vẹn không lỗi.

### Quy tắc
- Làm trên nhánh tách từ `develop`, mở Pull Request vào `develop`, nhắc Issue này (`Closes #<số Issue>` khi Pull Request cuối cùng của Issue được ghép).
- Chỉ sửa file thuộc phần của mình; cần đổi file dùng chung thì báo TV1.
- Kiểm thử sẽ làm sau khi hoàn thành chức năng, theo Testing Document Template của thầy.
